# CyberShield Academy | 実践セキュリティ啓発ポータル

日常や業務で直面するサイバー脅威を体験しながら学べる、静的Webサイト型のセキュリティ啓発教材です。

- **6つの基礎セキュリティテーマ**（各テーマ知識確認クイズ付き）
  - フィッシング・スミッシング・偽QR（クイッシング）
  - パスワード管理・MFA・パスキー
  - 生成AI詐欺・ディープフェイク・ClickFix
  - 端末・ブラウザ・パブリックWi-Fi
  - クラウド共有・誤送信・シャドーIT
  - ランサムウェア＆インシデント初動
- **実践トレーニングラボ**
  - フィッシングメール／SMS見抜き訓練
  - パスワード強度シミュレーター＆パスキー仕組み体験（ブラウザ内完結・外部送信なし）
  - URL構造＆なりすましドメイン判定ラボ
  - 総合理解度確認テスト（全6問）
- **日常セキュリティ・セルフチェックリスト**
- **緊急時初動マニュアル＆よくある疑問（FAQ）**
